### Security

- Retire the in-repository SSH-only host-ingress guard by the owner's 2026-11-02 decision, which supersedes PLAT-DEC-001 and safety invariant 16: its installer, recovery, custody and load scripts, systemd units, private-input contract and validators, transaction fixture, tests, assurance note, make target and CI steps are deleted. The runtime installer's collision gate no longer tolerates the guard's kubelet drop-in and now proves drop-in absence on disk: a containerd or kubelet `<unit>.d` entry in any system unit search directory refuses, and so does a directory whose absence cannot be established, because manager-backed `systemctl cat` cannot see a drop-in whose unit has no fragment; the type-wide `service.d/` policy is left alone. The host enforces its own posture (host firewall, VPN kill switch, ADR 0018), and the Phase H decisions register records the supersession.
