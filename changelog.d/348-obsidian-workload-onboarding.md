### Added

- Onboard the `obsidian` workload into the reconciliation graph: its own restricted namespace, hash-bound namespace budget and container defaults, namespace-owned default-deny, least-privilege reconciler and Helm identities, direct Flux Kustomization, and a cosign-verified chart source pinned to a fail-closed placeholder digest until snaraj/obsync publishes its first release.
- Add the third public Tunnel connector to the `cloudflare-public` chart, values schema, suspended release, and its own origin-egress NetworkPolicy, pinned by instance to the label the obsync chart actually publishes rather than to the namespace name.
- Add an `obsync-release-publisher` acquisition profile so the promoter verifies a workload whose chart and image are named for its artifact family while its namespace and Flux release are named for the workload, without guessing either.
- Move the reviewed namespace budget from one shared five-value map to one exact map per namespace, each bound to the exact bytes of its own capacity-evidence document, across the repository validator and both Conftest policy sets.
- Extend the release-transition classifier, the renderer's authoritative plan, and the release-state contract to every reconciled workload, so a workload staged behind an unresolved chart selection cannot be invisible to the mode that selects the release policy suite.
- Add the pending chart-source state as a narrowing: a workload with no published release may select only the all-zero sentinel, and a released workload may select only a nonzero digest, so a real digest cannot reach a manifest without the reviewed change that records its acquisition pair.
- Add the third identity tuple's hostile negative controls: an origin selector built from the namespace name, a cross-workload connector token, a cross-workload chart publisher, a foreign chart repository, another namespace's approved budget, and a sibling workload's image are each denied with one exact reason.
