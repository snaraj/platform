### Changed

- Route the owner-run Cloudflare account audit through the pinned `cf` CLI instead of raw REST requests: every provider command is schema-checked as a bodyless GET before any authenticated read, collections are paged to exhaustion within time and size bounds, and the one just-in-time read-only user API token reaches `cf` only through `CLOUDFLARE_API_TOKEN`, with its permissions, total lifetime and resources (one account, all of that account's zones, one user) proved before use.
- Fail the zero-charge gate unless subscriptions are permanent, zero-priced Free plans with no priced component, current-period cost, billing history, unpaid invoices and debt are all zero, and every zone of the account has only Universal certificate packs; a zone outside ADR 0006's allowed set is a finding, and the hardening, DNSSEC, Tunnel and DNS checks cover the three platform zones, with private hostname routes now also refused.
- Record `sloptube.fun` as a fourth Free zone in an ADR 0006 amendment (an owner project this platform does not serve, held to the zero-spend checks only), and move the account-audit and Tunnel force-disconnect runbooks and the agent contract to the `cf` path (#402).
